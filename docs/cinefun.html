TrailerQuiz

Create traffic for your movie theater using our TrailerQuiz. Your users can earn gold coins or prizes by watching trailers and answering quiz-questions about the movie trailer.

There can be up to 6 different TrailerQuizzes in the app.

  1. Movie poster
    Movie title

  2. Movie poster

    Take quiz
    2 Read about the quiz and prize

  3. Movie trailer in full screen

    3 Watch the trailer

  4. Questions that can only be answered if you have seen the trailer

    Answer 1 Answer 2 Answer 3
    4 Answer 3 questions

  5. The result

    The prize
    5 Win gold coins or a prize

To be able to make a TrailerQuiz we need:

  • Movie poster
    File type: png or jpeg
    Dimensions: 1080 x 1920
    Max size: 2 mb

  • Trailer
    File type: mp4
    Codec: H264, AAC
    Max size: 20 mb

  • 3 questions with 3 answer options
    Number of questions characters: 100
    Number of answer characters: 45
