DCH

Setup the DCH

The DCH, the Digital Cinema Hub, is a powerful computer with Cinemataztic’s custom-built software that makes interactive experiences in the cinema possible.

The DCH is placed next to the film projector, is connected to the Cinemataztic Cloud and works smoothly with the cinema’s existing setup.

Just received your box? Then this is where you want to be: here you get help setting up the DCH so your guests can enjoy CineGame.

Installation

What you need

Before you install your DCH, make sure you have everything listed here.

There are 2 ways to set up the automation: the DCH can receive the signal from the TMS via the network, or as an analog signal. An analog signal must go through a 24V Digital Input Unit connected to the DCH.

Troubleshooting: if you can’t connect the DCH to your screen server because of missing plugs, try using an adapter.

Network automation
  • Cinemataztic DCH
  • Power cable
  • HDMI cable
  • Network cable
Analog automation
  • 24V Digital Input Unit
  • USB cable
If audio is not to go via HDMI
  • External audio interface

Installation

Network

A few requirements for the machine’s network connection.

Requirements
  • Connected to the internet over ethernet (RJ45)
  • The firewall must allow the machines to connect to our servers via ports 9933 (TCP/UDP), 80, 3024 and 443

More about setting up the network in Internal settings.

Installation

Automation

Cues/macros: the Cinemataztic machines can be configured to start games from two types of cues: ethernet or 24V.

Ethernet

Cues over ethernet need the least setup and no extra hardware. The machines listen for short messages over TCP that say which playlist/game to start. The machine must be on the same network/subnet as the screen server sending the cues.

Examples for Doremi and GDC.

24V I/O

Needs 2 extra pieces of hardware per Cinemataztic player:

  • LucidControl DI4 listens for 24V cues to trigger a playlist/game.
  • Some cinema playlist software needs a 24V pulse back to resume the playlist after the CineGame. LucidControl DO4 sends this cue back to the cinema’s 24V automation equipment.
Software

Software installation

Boot the player from the inserted USB stick.

Troubleshooting: if you can’t boot from the USB stick and booted with the HWE kernel (recommended), try without HWE, and vice versa.

On a Shark
  1. Download the 20.04 live-server-amd64.iso and flash it onto a USB stick (we recommend balenaEtcher)
  2. Insert the USB stick in the machine you want to install
  3. Power on the machine and immediately tap F8 or Delete repeatedly until a BIOS screen appears
  4. In the BIOS menu, press F8 to open the boot select menu
  5. Select UEFI USB
  6. The install may look stuck, but please be patient. When it is finished, the PC powers off. If an error occurs, check the network cable and try again
  7. Remove the USB stick and power on the PC
On a Dell

By default the machine boots from the internal hard disk. To boot from the USB stick:

  1. Connect a keyboard to the machine and find the F12 key
  2. Power on the machine
  3. Press and release F12 repeatedly until a boot select menu appears
  4. Select “Boot from UEFI USB” and press Enter
Configuration

Authorize

Make sure the player is powered on and connected to the internet. The player shows an “Authorize player” screen with its ID.

Authorize the player

Troubleshooting: if the DCH does not show ‘Authorize player’ after booting: is it connected to a network with internet access? Does the network need manual settings (static IP, name servers etc.)?

  1. Go to your admin panel at cloud.cinemataztic.com and log in

    Troubleshooting: can’t log in? Try the reset password option, or contact Cinemataztic for help.

  2. Select “Players” in the left menu
  3. Look up the player by the ID shown on the screen and click “Authorize”
  4. Wait for the machine to pick up the authorization. This may take a while
Configuration

Connect to screen

Make sure the player is powered on. It now asks you to assign it to a screen.

Troubleshooting: if the DCH does not show “Connect player to screen” after authorizing, give it time: it can take at least 10 minutes to detect its authorization.

Connect the player to a screen
  1. In your admin panel at cloud.cinemataztic.com, choose “Cinemas” in the left menu
  2. Choose your cinema in the left column and the screen you want in the rightmost column. You can create a new screen or connect to an existing one
  3. Only for a new screen: choose a name (e.g. 01 for auditorium 01), write a short description (optional) and select a hostname. The system suggests one in the format CIT-CIN-SCREEN (city-cinema-screen), first in the dropdown
  4. Find the “Player” card, click “Assign player” and choose the player by the ID shown on the cinema screen
  5. Wait for the machine to pick up the new configuration (5–10 minutes). When the “Connect player to screen” message disappears, the machine is ready

The player is now connected to the screen. Congratulations!
