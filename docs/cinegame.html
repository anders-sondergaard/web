CineGame

CineGame is an interactive branded game played by the audience on the cinema screen as part of the preshow. The audience use the CineGame app to connect with the game.

CineGame has been running since 2013 in Odeon and Nordisk Film cinemas in the Nordics and is now also available in cinemas in Germany, Portugal, Sweden & Ireland.

Why CineGame is a great solution for everyone

Cinema

CineGame offers you an opportunity to entertain your guests before the movie has even begun. That’s a great way to stand out from your competitors.

Advertiser

Gamification is a fun and more memorable way to make a lasting effect on consumers than regular advertising.

Brand safety

A CineGame is a closed system with complete control over everything. Nothing can get on the cinema screen or into a CineGame app without having been through Cinemataztic’s quality control.

Fundamentals

How to play

Cinema guests enter the 4-digit code written on the screen. Then their CineGame app is transformed into a joystick that allows them to write messages, move their avatar around the screen, answer questions or control a spaceship on the cinema screen.

Fundamentals

CineGame flow

A CineGame is almost always built up over 3 stages: the audience logs on, the game is played, and the winner is found and a prize is awarded.

The length of the stages can vary from market to market and game to game.

  1. 01 Lobby The audience logs on

    The lobby is the first thing the audience experiences. Here they see how they take part in the game and what they can win. It can hold graphic elements, 3D animations, video, sound effects and of course music.

  2. 02 Game The game is played

    The game can be almost anything: nearly any game can be turned into a CineGame, and every element of it can be adapted to the brand.

  3. 03 Winner The winner is found

    The winner is shown on the screen together with a picture of the prize and any tagline, and the prize is sent to the winner's CineGame app.

Prizes go to the winner and / or everyone who took part, straight into their CineGame app.
Fundamentals

Timing

A CineGame can last from 3 to 10 minutes and can be placed anywhere in an existing preshow.

Demo

How to run a demo

So now you have a Cinemataztic player in your cinema, it’s connected to the backend, and you want to show it to everybody!

Important: there are two ways to demo the Cinemataztic player, and a setting on the player MUST match the type of demo. If it is not set correctly, the demo will fail and leave a bad impression.

You can show the scheduling system, OR just show the games on the player.

Show the scheduling system

The Cinemataztic player works with different cinema automation systems (like Doremi). How you show your system is out of scope here, but the player must be configured as usual.

If you have demoed the games on the player as described in the next card, you must remove the checkmark from the “Ignore game cooldown” setting:

  1. Find the correct Cinemataztic player in the Cinemataztic Cloud
  2. Open its settings
  3. Make sure “Ignore game cooldown” is not set

If it is left on while showing the backend and you start games in quick succession, the games will end before time. So this kind of demo must use full game sessions only.

Show the games on the player

If you only want to show the different games, and perhaps skip the lobby, restart games before time, or exit games and start new ones, this method is for you.

To freely start, stop and skip games, the “Ignore game cooldown” checkmark must be set. Uncheck it again before going back into production and before showing the backend scheduler.

  1. Find the correct player as above and change these settings
  2. Make sure Show GUI is set, and consider setting the player’s playlist to “DEMO”
  3. Connect a keyboard directly to the player: you can now start the games directly from the list

Keyboard shortcuts

  • In the menu: 1–9 starts the game with that number, P makes a ping sound
  • In the game: Alt + F4 ends the game running now
  • In the game lobby: hold S, then hit Space to skip the lobby
