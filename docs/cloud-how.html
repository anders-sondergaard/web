How to use the Cloud

A tour of the Cinemataztic Cloud, from the dashboard to the settings.

Dashboard

On your dashboard, a few widgets give you an overview of the status of your machines and how your campaigns perform.

Screen status

A list of all your machines. A red circle next to a machine means no reel has run on it in the last 24 hours. This may be due to:

  • No internet connection
  • The machine is switched off
  • The machine gets no signal from the TMS
Total use

How many attendees there have been across all campaigns in a given period.

Active quizzes

Which Trailer Quizzes are live in your app.

App version

Which apps are live in the App Store and Google Play. Useful to know in support cases.

News from Cinemataztic

Changes and additions to the Cloud are described here.

Game Center statistics

How many people take part in your CineGame+ games (in-app games).

Desktop app

Download Cinemataztic’s desktop app. It must be used to run a game from an unauthorised computer.

Cloud

Statistics

Statistics you can see in real time: how the individual cinema halls, on-screen games and CineGame+ games perform.

You can download the data for a selected period as a CSV file.

Screen performance

See how each hall and all halls together have performed. Hover over a hall to see its numbers.

Game performance

Pick a game and a period to see how it performed day by day, with an overview of the whole period.

Game Center performance

Pick a game and a period to see how a CineGame+ game performed day by day, with an overview of the whole period.

What the numbers mean
  • Views: how many games have been started
  • Games: how many games have been started with at least 1 participant
  • Players: how many unique participants there have been
Cloud

Cinemas, games & more

The other pages in the Cloud menu, and what you use them for.

Cinemas

A complete list of your cinemas. Open each cinema’s and hall’s settings from here.

Players

A complete list of your machines. Open each machine’s settings from here.

Playlist

The playlists decide what is played in each cinema. Most markets have a “LIVE” playlist that is constantly updated with new games. In markets with several cinema chains, each chain typically has its own playlist.

Games

All games developed for your market. Only games with a green tick are ready for settlement; games without one may be affected by updates or other issues.

Logs

If something goes wrong, you need fast access to the log files. All log files are saved here.

Support

When a user has problems with their app, prizes or other parts of the platform, they can contact the app’s administrator via a support form. The inquiries appear here, and you can assign them to someone on your team or send them on to Cinemataztic support.

Prizes

Which prizes are live (can be won right now), how many have been handed out and redeemed, and how many codes a prize has left.

CineFun

Which games are live in CineFun.

Users

Look up a single user and see which games they have played, the prizes they have won and redeemed, and other info they have chosen to share with CineGame.

Promo

In markets with CineCard: create discount codes that can be used when a user creates a CineCard.

Aptly

Used only by Cinemataztic to monitor machines and player software versions.

Message center

Send messages to your users: to everyone, to a target group or to individual users.

How to send a message
  1. Press New message (the pencil icon)
  2. Select the recipient(s). For a single user you need the support ID from the app, which the user must give when contacting you via the support form
  3. Write the message
  4. Optionally link to a place in the app
  5. Select the expiration date, when the message disappears from the app
  6. Press Send
Cloud

Profanity

Our profanity filter makes sure no swear words are shown on the big screen.

There are two lists: a global one, updated by Cinemataztic, and a local one, which the app provider is responsible for. Please add words to the global list when they work across countries and languages, so all markets help each other.

How to add a word
  1. Select Global or Local
  2. Write the word in the input field
  3. Not already on the list? Press +
Be creative

If you add the word “Boobs”, you may also need to add “Booobs”.

Cloud

Trailer Quiz

View and create Trailer Quizzes. A small green light on a Trailer Quiz means it is live.

How to create a Trailer Quiz
  1. Press New Trailer Quiz (the small + symbol)
  2. Select the collection
  3. Select the priority (no. 1 appears first in the app, no. 2 second, etc.)
  4. Campaign ID (e.g. MovieName_July_2022)
  5. Title (e.g. MovieName), shown in the app
  6. Subtitle (e.g. Guess and win)
  7. Details (e.g. Watch the trailer for the fantastic MovieName and win cool prizes)
  8. Poster: upload the movie poster
  9. Background poster: upload the movie poster
  10. Video: upload the trailer
  11. Share URL (e.g. www.buytickets.com)
  12. Questions: create 3 questions, each with 3 answer options, and enter the correct answer
  13. Prize type: hand out gold coins or prizes for 1, 2 or 3 correct answers
  14. Press Save
